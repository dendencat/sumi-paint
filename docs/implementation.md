# 初期実装の範囲と確認項目

## 実装した構成

Macのネイティブターゲットと、iPhone・iPad共通のiOSターゲットがあります。SwiftUIで操作画面を作り、UIKit・AppKitで入力を受け取り、Metalでブラシ描画と合成を行います。共通処理にはFoundationのみを使います。

ストロークは作品座標で補正・補間します。実測の筆圧がない入力は一定の太さとし、始点の細まりを選択できます。iOSのcoalescedTouchesを使用します。予測入力、傾きによるブラシ形状の変更、ホバー表示は後続項目です。

## 設計案との関係

[設計案](design.md)は中長期の方針です。現在の実装は次の範囲です。

- レイヤー画像は1枚ずつのMetalテクスチャに保持します。変更した128×128の領域をUndoに保存し、合成も変更領域だけ更新します。
- 作品保存はレイヤーごとのRGBA画像と設定を含むバイナリProperty Listです。ディスク上のタイル分割・圧縮・読み込み時の退避は後続項目です。
- メモリ上限を明確にするため、最大2048×2048・8レイヤーとします。履歴は64 MiB・100操作までで、上限を超える古い履歴から破棄します。
- 手ぶれ補正は時刻を考慮した平滑化と、ペンを離した後の終点処理です。補正による追従の遅さを設定できます。
- 変形は選択画素を確定する方式で、最近傍補間を使用します。Undoで戻せます。変形中の連続プレビューや非破壊変形は後続項目です。
- 塗りつぶしは現在のレイヤーと選択範囲を参照します。全レイヤー参照や隙間閉じは後続項目です。
- 自動復旧は確定した編集の2秒後を目安に保存します。描画中・処理中は延期します。保存は世代順を管理して原子的に置き換えます。強制終了直前の未保存の編集は失われる可能性があります。
- 水彩・混色、編集可能な曲線、レイヤーグループ・マスク、PSD、自動クラウド同期は後続項目です。

GPUメモリのほか、合成用テクスチャ、履歴、保存・塗りつぶし・変形用の一時データが必要です。画像データ128 MiBという上限は、アプリ全体の使用メモリの上限ではありません。

## 自動テスト

共通処理: 入力頻度に依存しないブラシ間隔、筆圧と代替入力、補正の終点、不正な入力、座標変換と拡大の中心、選択の境界、塗りつぶし、変形、保存の往復、不正なファイルの拒否。

Appleプラットフォームの統合テスト: GPUでの描画・消去、Undo・Redoでの画素復元、選択による描画制限、キャンセルした描画の復元、レイヤー操作、作品保存・PNG書き出し、クリッピング・乗算。

シミュレーター確認: iPhone・iPadにアプリをインストールして起動し、プロセスの継続と画面を確認。これだけでは描画操作や筆圧の動作は確認できません。

## 実機で確認する項目

- 対応するペン・ペンタブの筆圧取得、軽い線、入り・抜き。
- 補正なし・弱い補正・強い補正で、円・角・速い線を描く。
- 25%・100%・400%の倍率でブラシの太さが作品上で変わらないこと。
- 指とペンの切り替え、2本指の操作、2本指タップのUndo。
- Macのペンタブのドライバ差、トラックパッド、キー操作。
- 2048×2048・8レイヤーでの長時間描画、保存、変形、メモリ警告時の挙動。
- Macで保存した作品をiPad・iPhoneで開き、再編集してMacへ戻す。
- 縦長・横長・小さいウィンドウでのパネル操作、VoiceOver、色選択。

60fps等の実機での性能は、この初期実装ではまだ測定していません。
