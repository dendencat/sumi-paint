# レイヤー・カラー・レイアウト改善（2026-10-15）

`/tmp/sumi-review/spec.md` と Codex / Claude の事前レビューに対応。レイヤー、カラー、macOSレイアウト、レビューHigh不具合の順に実装した。

## 仕様への対応

- レイヤー行は表示切替、40×40のチェック柄付きサムネイル、名前、不透明度。選択行に塗りと左3ptのmint線。名前をダブルクリックして編集し、Enterまたはフォーカス移動で確定する。コンテキストメニューからも編集できる。
- 一覧上部に合成・不透明度・ロック類を常設。一覧だけがスクロールし、追加・複製・上下移動・削除は下部に固定。ドラッグで並べ替え、クリッピング行を12ptインデントして↳を表示する。
- 不透明度はドラッグ中も合成へ反映し、開始から終了までを1回のUndoにする。途中の自動保存や再描画がスライダーの値を戻さない。
- HSVリングとSV四角、HEX入力、重ねた描画色／背景色、Xキーでの入替。最近使った色は実際の描画・塗りつぶし・スポイト終了時に登録し、最大8色。保存カラーセットとは分離し、＋で追加、長押しまたはメニューで削除する。両方をUserDefaultsに保存する。
- 色見本は24×24、選択色は白2pt枠、アクセシビリティラベルにHEXを含む。HSVもアクセシビリティ操作で調整できる。
- Macは52ptのアイコンツール列、220ptのプロパティ、キャンバス、260ptのカラー／レイヤー列。上部にブラシ簡易バー。左利きでは左の2列だけを入れ替え、キャンバス位置を維持する。iPadの広い画面もレイヤーを独立してスクロールできる。

## High不具合と関連修正

- Macのフォーカス喪失で一筆を消さず確定する。明示的なEscapeは取り消す。
- クリッピング群は基底の画素αを維持して合成し、基底の不透明度と合成モードを最後に1回適用する。最下層のクリッピングを禁止し、移動・削除による補正も同じUndoに含める。クリッピング列の途中に挿入する新規層はクリッピングを継承する。
- iOSの2本指Undoは仮の点を破棄してから前の操作を戻す。2本目の接触やピンチ・回転開始でも仮の描画を破棄する。Pencilの移動ツールも入力を受け付ける。
- 選択なしの画素消去をエンジンとメニューの両方で禁止。空マスクをnilへ正規化し、CPU/GPUの選択判定を統一する。
- ストロークの最大被覆を作業テクスチャに保持し、毎回、一筆開始前の画素へ一度だけ合成する。一筆内の重なりで不透明度を超えず、別の一筆は通常どおり重ねられる。消しゴム・透明度保護・選択範囲にも適用する。
- 塗りつぶしは合成画像を境界判定に使い、選択レイヤーへ書き込む。ブラシ不透明度を反映し、0〜8pxの領域拡張で線の縁を埋める（初期値1px、選択範囲を越えない）。
- ツールごとのブラシ設定を保持し、切替による硬さ・サイズのリセットを防ぐ。追加レイヤー履歴への不要な画像容量の計上も除いた。

## 復旧ファイル

起動時と書込み後に、編集中のチェックポイントを除き、最新5件・7日以内・合計256MiBに整理する。復元した作品は同じチェックポイントへ保存し、セッションごとの複製を作らない。同じ復旧版を別の編集中ウィンドウも使用している場合は、互いを上書きしないよう別のチェックポイントを作る。

作品ファイルの保存成功後、保存した版が現在の編集と一致している場合にその復旧版を削除する。古い版の書き出しやPNG出力では最新の復旧版を消さない。書込み中の処理があれば完了を待つ。

**未保存作品の唯一のコピーを消さないため、正常終了時も未保存の復旧版は保持する。** 正常終了時と復旧ダイアログの確認時に更新日時を既読として記録し、同じ版について毎回アラートを出さない。確認後に更新されたチェックポイントは再度通知する。残った版は復旧ファイル管理から開ける。

## 検証範囲

DrawingCoreの単体テストと、実際のMetalデバイスを使うmacOS AppTestsで検証。途中の不透明度とUndo、半透明クリッピング、並べ替え・削除のUndo、Xキー・パレット永続化、フォーカス喪失とEscape、仮の点を伴うUndo、選択なしの消去、ブラシの不透明度上限、別層参照の塗りつぶし、復旧の保持上限・再利用・既読・保存後の削除を含む。

macOSとiOS Simulator向けのビルドも確認する。ネイティブアプリ操作のアクセス制限により画面の目視確認は未実施。iOSの指・Pencil・実機ペンタブの操作感は実機確認が必要。
