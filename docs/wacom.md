# MacでWacomのペン・ボタンを使う

## 対応の仕組みと確認状況

アプリはAppKitの標準イベントから筆圧・クリック・キー・ペンの反転を受け取ります。WacomドライバがmacOSへ送る入力を扱う構成で、Wacom SDKやドライバのコードをアプリへ組み込んでいません。

筆圧の取得、ボタン割り当て、一時的なツール切り替え、消しゴム側の自動切り替えを実装しています。自動テストでは合成したマウス・キー入力と反転通知に対する処理を確認します。Wacomの実機・ドライバを使った互換性や描き心地は未確認です。ペンやボタンの機能は機種と設定によって異なります。

## ボタンを割り当てる

1. 対応するWacomドライバをインストールし、Wacom Centerで機器を選びます。macOSでドライバが要求する権限を設定してください。
2. Sumi Paint用のアプリケーション別設定を作成し、「アプリケーション」フォルダの `Sumi Paint.app` を指定します。
3. ペンボタンの1つに「右クリック」、もう1つに「中クリック」を割り当てます。ボタン数・名称は機種によって異なります。
4. Sumi Paintの右上メニュー →「ペンタブのボタン設定」を開き、各クリックに対応する動作を選びます。

| 設定できる動作 | 動作 |
| --- | --- |
| 押している間スポイト | ボタンを押して色を取得、離すと元のツールへ戻る |
| 押している間キャンバス移動 | ボタンを押してドラッグで移動、離すと戻る |
| 押している間消しゴム | ボタンを押している間、ペン先の接触で消去。離すと元のブラシへ戻る |
| 描画ツールと消しゴムを切り替え | ボタンを押すたびに切り替え。消しゴムから戻ると、直前のペンまたは鉛筆の設定へ戻る |
| 元に戻す / やり直す | Undo / Redo |
| 割り当てなし | アプリ側ではボタン動作を行わない |

初期設定は「右クリック＝押している間スポイト」「中クリック＝押している間キャンバス移動」です。通常のマウスの右・中ボタンにも同じ設定が適用されます。設定はMac上に保存し、作品ファイルには含めません。

一時切り替えから戻ると、サイズ・硬さ・筆圧カーブなどの元のブラシ設定を復元します。描画中のツール変更は、それまでの線を確定してから切り替え、移動した位置へ線をつなぎません。ウィンドウやキャンバスが入力フォーカスを失うと、押しっぱなしの状態を解除します。

## ExpressKeysなどにキーを割り当てる

Wacom側でキーボードショートカットを設定する場合は、次を使用できます。

| キー | 動作 |
| --- | --- |
| `B` / `P` / `E` | ペン / 鉛筆 / 消しゴムへ切り替え |
| `X` | 描画ツールと消しゴムを切り替え |
| `H` / `I` / `G` | 移動 / スポイト / 塗りつぶしへ切り替え |
| `Space`を押している間 | 一時的にキャンバス移動 |
| `Option`を押している間 | 一時的にスポイト |
| `Command-Z` / `Command-Shift-Z` | Undo / Redo |
| `[` / `]` | ブラシサイズを小さく / 大きくする |

一時操作は、キーを押す・離す情報をドライバが送る設定で使用してください。短いキーストロークだけを送る設定の場合は `B`・`E`・`X`などの切り替えを使います。レイヤー名などの文字入力を妨げないよう、単独キーはキャンバスに入力フォーカスがある場合に扱います。まずキャンバスをクリックしてください。

## ペンの消しゴム側

「消しゴム側で自動切り替え」を有効にすると、対応ペンの消しゴム側が認識された間は消しゴムになります。ペン先に戻すと元のツールとブラシ設定へ戻ります。消しゴム側のないペンや、ドライバが反転の情報を送らない場合は、ボタンまたは `E`・`X`で切り替えてください。

## 実機で確認すること

- 筆圧の軽い線・強い線と、ドライバ側のペン先感触設定。
- ボタンの押下・ドラッグ・解放、描画中の切り替え。
- ペンを反転して消去し、再び戻したときのブラシ設定。
- ボタンを押したまま別のアプリへ移った後に、モードが残らないこと。
- 複数のボタン・Space・Optionを組み合わせた操作。
- 複数ウィンドウ、複数ディスプレイ、アプリケーション別のドライバ設定。
